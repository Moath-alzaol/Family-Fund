1. Home dashboard
2. New request types

All files in the preferred Arabic folder are `1320 × 2868` JPEGs with no alpha channel, ready for the 6.9-inch App Store Connect screenshot field. They were captured natively from the app on an iPhone 16 Pro Simulator at `1206 × 2622`, then exported to the exact size requested by App Store Connect.

The six Arabic phone captures supplied later were originally `591 × 1280`, which App Store Connect rejects. The files in `ar/phone-1320x2868` are the corrected `1320 × 2868` versions and are ordered for upload. Do not upload the original attachment files.

Only upload the six files from `ar/native-appstore-1320x2868` for the Arabic localization. The web and supplied-phone folders are retained as fallbacks and should not be mixed with the preferred set.
